# D&D 5R 角色卡

可直接在瀏覽器填寫的 D&D 5R 角色卡（三頁），每個格子都能編輯，並可下載成 Letter 尺寸 PDF。

線上使用：https://vincentchiu-insightsoftware.github.io/dnd-sheet/

- 填寫內容只存在自己的瀏覽器，不會上傳
- 「匯出存檔／匯入存檔」可以把角色資料存成 .json 帶著走
- 「清空全部」可以變成空白角色卡
- 手機打開會自動變成直式表單（表單模式），按「紙本預覽」可以看原本的角色卡版面

## 自動填寫版

https://vincentchiu-insightsoftware.github.io/dnd-sheet/auto/

選職業、等級、物種、背景，填屬性基礎值，其餘依 2024 版玩家手冊規則自動計算：屬性調整值、熟練加值、豁免、技能、先攻、防禦值、速度、生命值、武器命中與傷害、施法 DC 與法術位，並自動帶入物種特性、背景專長、職業特性、熟練項和語言。

規則數據參考：https://www.yuque.com/power_word_club/phb2024
